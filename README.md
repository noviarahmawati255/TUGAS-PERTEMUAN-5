# TUGAS-PERTEMUAN-5
Program Kategori Pengeluaran dibuat menggunakan HTML, CSS, dan JavaScript untuk mencatat pengeluaran mahasiswa dan mengelompokkannya berdasarkan jumlah uang yang dikeluarkan.

1. HTML digunakan untuk membuat struktur halaman, seperti kolom nama, jumlah pengeluaran, tombol simpan, riwayat, dan total pengeluaran.

2. CSS digunakan untuk mengatur tampilan program, seperti warna biru, ukuran, jarak, dan bentuk tombol.

3. JavaScript digunakan untuk mengolah data pengeluaran dengan percabangan dan perulangan.

4. Percabangan (if, else if, dan else) digunakan untuk memvalidasi input dan menentukan kategori pengeluaran, yaitu Sangat Hemat, Hemat, Sedang, Boros, Sangat Boros, dan Pengeluaran Besar.

5. Perulangan for digunakan untuk menampilkan seluruh riwayat pengeluaran yang telah dimasukkan.

6. Perulangan while digunakan untuk menghitung total seluruh pengeluaran.
